# Handoff, 2026-10-23: the ISLES 2018 evaluation of the fold models, built

Branch `ctp-only`. Today's work is built and checked for syntax only. Per the compute
workflow, none of it has run yet: every step below runs on the box. The design is
`ctp_only_eval_plan.md` §6.1, and today's choices are decisions #25. The training state is
in `handoff_2026-10-20.md` and in the 10-21 session: rCBF fold 0 and Tmax fold 2 were killed
on 10-20 at 16:53 by a cluster-wide event and restarted by hand from checkpoints 70 and 50.

## What's built

| piece | what it does | where it runs |
|---|---|---|
| `scripts/ctp_only_isles18_maps.py split` | `isles2018/split.json`: the 94 scans as `val_case_ids`; refuses unless 94 / 63 / 502 and both indexes agree | 14958, docker |
| `condor/ctp_only_stage_isles18.sub` | `/radraid2` stage → H100 `/home`, checked, `STAGED_OK_isles18` | H100, no GPU |
| `scripts/ctp_only_isles18_dag.py` | a DAG of `ctp_only_test_h100.sub` tests (`testset = isles18`, full), one per fold whose run reached checkpoint 200 and has no complete ISLES test yet; `--dry-run` only lists the folds | 14958, plain python3 |
| `condor/ctp_only_isles18_ganbpm_maps.sub` | gan_bpm's 30 fold models on the 94 scans as stage-1 maps; first reproduces stage 1's stored maps | 14958, 1 GPU, < 1 h |
| `scripts/ctp_only_isles18_maps.py mrdpm` | MRDPM test folders → stage-1 maps (clipped to [−1, 1]); refuses a missing slice, a wrong envelope or label, a changed checkpoint | 14958, docker |
| `scripts/ctp_only_isles18_score.py` | scores everything with gan_bpm's stage 2; checks first; per-fold tables, fold means, fold-averaged paired differences | 14958, docker, ~1 h |
| `condor/ctp_only_test_h100.sh` | now also writes `source_run.json` (training folder, epoch, EMA sha256) | H100 |

Everything lands under `/radraid2/colivares/mrdpm_ctp_only/isles2018/`: `split.json`,
`maps/<run>/<snapshot>/`, `eval/<date_time>/` (CSVs, `checks.csv`, `summary.txt`).

## The steps, on 14958

`git pull` first. `d` runs a command in the job image from the repo root, wherever you are.
Every CPU step uses it; define it once per shell:

```bash
cd /raid/colivares/github_repos/MRDPM-with-RAP_fork && git pull
d() { docker run --rm --shm-size=8g --user "$(id -u):$(id -g)" -e NVIDIA_VISIBLE_DEVICES=void \
      -e HOME=/tmp -e MPLCONFIGDIR=/tmp/mpl -e PYTHONDONTWRITEBYTECODE=1 -v /raid:/raid -v /radraid2:/radraid2 \
      -v /raid/colivares/github_repos/MRDPM-with-RAP_fork:/repo -w /repo \
      registry.cvib.ucla.edu/colivares:mrdpm-env-v1 "$@"; }
```

0. **Where training is:** `python3 scripts/ctp_only_isles18_dag.py --dry-run` (one line per
   target and fold: trained, tested, or the newest checkpoint); `condor_q -run` for the GPUs.
1. **The split and the `/radraid2` copy** (CPU, a few minutes):
   ```bash
   d bash -c 'python scripts/ctp_only_isles18_maps.py split && for t in rcbf tmax; do
     python scripts/ctp_only_stage_data.py /raid/colivares/mctp_dataset_msu_f13_isles2018_all94 \
       /radraid2/colivares/mrdpm_ctp_only/stage/isles2018/mctp_dataset_msu_f13_isles2018_all94 \
       --split /radraid2/colivares/mrdpm_ctp_only/isles2018/split.json --side val --label-type $t || exit 1; done'
   ```
2. **Stage it on the H100, and gan_bpm's fold maps** (these two can run at once; the second
   holds a GPU):
   ```bash
   cd condor && mkdir -p log
   condor_submit ctp_only_stage_isles18.sub
   condor_submit ctp_only_isles18_ganbpm_maps.sub
   ```
   Paste back the stage job's `.out`, and the maps job's two `check` lines and its summary.
3. **Score once with no MRDPM map yet:** this runs the stage-2 reproduction check, and
   nothing MRDPM-related, so a scoring problem shows up before 40 GPU-hours of sampling:
   `d python scripts/ctp_only_isles18_score.py --target rcbf` (in `screen`; paste the PASS/FAIL lines).
4. **A debug ISLES test** (4 slices, minutes) on one trained fold, after step 2's staging:
   ```bash
   R=$(ls -d /radraid2/colivares/mrdpm_ctp_only/runs/train_ctp_only_f13_rcbf_fold4_* | head -1)
   condor_submit ctp_only_test_h100.sub -append "run = $R" -append 'testset = isles18'
   ```
5. **The tests:** `python3 ../scripts/ctp_only_isles18_dag.py --maxjobs N`, with N the GPUs
   free under the cap of 3, then `condor_submit_dag` on the file it names. About 4 h per
   test; rCBF first. Rerun the script as more folds finish: it skips what's tested.
6. **Maps and scores, as tests finish** (in `screen`):
   ```bash
   d bash -c 'python scripts/ctp_only_isles18_maps.py mrdpm && python scripts/ctp_only_isles18_score.py'
   ```
   The scoring stops before any table if a check fails. `eval/<date_time>/summary.txt` is the
   thing to paste back.
