## 6. Gotchas learned today

- **Run folders carry a phase prefix:** `runs/train_…` and `runs/debug_…`, never bare
  `ctp_only_…`.
- **Docker on the box needs `--shm-size=8g`** (or `--workers 0`) for anything with DataLoader
  workers; the default 64 MB `/dev/shm` dies with "No space left on device". Condor jobs
  already ask for 8 GB.
- **`condor_wait` chains** must run inside `screen` (or `nohup`), from `condor/`, with `C` set
  in that shell. With an empty `C` the log path doesn't exist and nothing is submitted.
- **`git pull` on 14958 while DAGs run:** later DAG nodes start with the checkout as it is then.
  Today's changes keep Tmax jobs unchanged (`target` defaults to `tmax`); keep any future change
  to the job scripts backward compatible the same way.
- **Never rerun the Tmax staging** (`ctp_only_stage_home.sub` without `target`) while a job runs:
  it replaces gan_bpm's code under it. The rCBF staging is safe.
- **The laptop runs nothing** (memory: compute workflow). Syntax checks only; everything else is
  a paste or a Condor job on the box.
